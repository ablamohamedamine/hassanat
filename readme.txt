== Description ==
إضافة **حسنات** هي أداة مخصصة لمواقع الويب تهدف إلى نشر الخير وتذكير الزائر بالأذكار اليومية وأدعية مختارة. تعمل الإضافة على عرض الأذكار بشكل جميل وبسيط داخل الموقع، مما يساعد في زيادة الأجر وحث الزوار على ذكر الله أثناء تصفحهم.
